# Boombox Tuning Guide

Static GitHub Pages site for tuning an AIYIMA TPA3116 2.1 amplifier board.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload these files.
3. Go to **Settings -> Pages**.
4. Set source to **Deploy from a branch**.
5. Select `main` and `/root`.

## Tuning target

- 12 inch bass in 76 L sealed cabinet
- 2 x 8 inch drivers in 12 L sealed cabinet
- MPT-55 piezo with 0.68 uF series capacitor
- Bass FQR target: around 75-85 Hz
